# Olm Skip Trainer

A browser trainer for the Chambers of Xeric (OSRS) Great Olm duo/trio **mage skip**.

- **Play:** a top-down, tick-based Olm room. You run the 3-tile route at the head (left, middle, right) while your melee guy holds the melee side. There are drills for skipping, setting the skip, prayer switching (like a Jad trainer) and a full fight.
- **How it works:** the skip explained step by step.
- **Quiz:** telling mage from melee, prayer orbs, and the route.

Open `index.html` in any browser, or use the GitHub Pages link for this repository.

Mechanics are based on the OSRS Wiki and guides by Synq, Qevon and Daep. This is a fan-made training model, not affiliated with Jagex.

## Updating

Edit `olm_trainer.html`, then run `python make_index.py`, commit and push.
